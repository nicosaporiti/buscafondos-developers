# Estado y soporte

## Health check

[api.buscafondos.com/health](https://api.buscafondos.com/health) devuelve el estado del servicio, la última fecha scrapeada (`last_scraped_date`) y el total de registros. No requiere API key.

No existe página de incidentes ni SLA publicado. Un `status: ok` confirma que el servicio responde; no garantiza que todos los datos tengan la misma fecha.

## Soporte técnico

Escribe a [api@buscafondos.com](mailto:api@buscafondos.com) para reportar problemas reproducibles del contrato o de los datos, consultar por cuotas o solicitar un tier distinto. El backend no es de código abierto; este correo es el único canal técnico.

<Callout title="Solicitar más cuota">El tier `free` permite 300 requests/día ([límites por tier](/quotas-errors#limites-por-tier)). Si necesitas más, indica en el correo tu **requerimiento** (requests diarias estimadas, endpoints y frecuencia) y tu **justificación** (caso de uso y por qué la cuota `free` no alcanza). Incluye el email con el que registraste la key, nunca la key.</Callout>

<Callout title="Qué incluir en un reporte">Ruta, parámetros, código de estado, hora aproximada y `operationId` si aplica. Elimina la API key y cualquier header de autenticación antes de enviar.</Callout>

Para temas del producto BuscaFondos, no de la API, usa los canales indicados en la [política de uso](https://api.buscafondos.com/policy).
