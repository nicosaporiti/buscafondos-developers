# API keys

La emisión de keys ocurre en [api.buscafondos.com/register](https://api.buscafondos.com/register), que verifica el email y entrega una key gratuita del tier `free`, con una cuota de **300 requests/día**. El portal no reimplementa ese flujo.

## Emisión

1. Ingresa tu email en el registro.
2. Abre el enlace de verificación.
3. Guarda la key en ese momento: **se muestra una sola vez** y el backend conserva solo su hash.
4. Verifícala con `GET /api/key/info` enviando el header `X-Api-Key`.

<Callout title="Si pierdes la key" tone="warning">Repite el registro con el mismo email. La key anterior queda revocada al emitir la nueva.</Callout>

## Consumo y cuota

Los límites de cada tier están en [Cuotas y errores](/quotas-errors#limites-por-tier). Si necesitas más de 300 requests diarias, escribe a [api@buscafondos.com](mailto:api@buscafondos.com) indicando tu requerimiento (requests diarias estimadas, endpoints y frecuencia) y tu justificación (caso de uso y por qué la cuota `free` no alcanza).

`GET /api/key/info` devuelve tier, cuota configurada, si la cuota está siendo aplicada (`quota_enforced`) y `requests_today`. Las respuestas de los endpoints de datos incluyen el remanente y el instante de reset en los [headers de cuota](/quotas-errors).

## Operaciones no disponibles

El portal no ofrece rotación, revocación ni panel de consumo. Hoy la rotación se hace repitiendo el registro y el consumo se consulta con `/api/key/info`. El portal no almacena keys ni estado de cuenta.
