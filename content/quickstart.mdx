# Primer request

Registro, verificación de la key y primera consulta a un endpoint de datos.

## 1. Obtén la API key

Solicita una key gratuita en [api.buscafondos.com/register](https://api.buscafondos.com/register). La key queda en el tier `free`, con **300 requests/día** ([límites por tier](/quotas-errors#limites-por-tier)). Tras verificar el email, la key se muestra **una sola vez**; el backend conserva únicamente su hash. Guárdala en el gestor de secretos de tu entorno.

<Callout title="No la incluyas en el código fuente" tone="warning">Léela desde una variable de entorno del servidor. No la expongas en variables públicas del bundle, repositorios ni capturas de pantalla.</Callout>

## 2. Verifica la key

<CodeExample title="curl" language="bash" code={`curl https://api.buscafondos.com/api/key/info \\
  -H "X-Api-Key: $BUSCAFONDOS_API_KEY"`} />

`/api/key/info` devuelve tier, cuota diaria y consumo del día. Esta llamada no descuenta cuota.

## 3. Consulta fondos

<CodeExample title="JavaScript / TypeScript" language="typescript" code={`const response = await fetch(
  "https://api.buscafondos.com/api/all-funds?category=money_market",
  { headers: { "X-Api-Key": process.env.BUSCAFONDOS_API_KEY! } },
);

if (!response.ok) {
  throw new Error(\`BuscaFondos respondió \${response.status}\`);
}

const payload: unknown = await response.json();`} />

<CodeExample title="Python" language="python" code={`import os
import requests

response = requests.get(
    "https://api.buscafondos.com/api/all-funds",
    params={"category": "money_market"},
    headers={"X-Api-Key": os.environ["BUSCAFONDOS_API_KEY"]},
    timeout=20,
)
response.raise_for_status()
payload = response.json()`} />
